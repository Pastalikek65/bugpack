# Roadmap

The 0.1.0 MVP introduced local HAR/log/screenshot review and clean ZIP export with actual Windows/Linux package acceptance.

The 0.2.0 beta added versioned policies, bounded literal custom rules, supported JSON/form body cleanup, explicit unsupported omissions, batch processing and the shared-engine CLI. Its exact Windows/Linux CI and package flows passed; release evidence is recorded per version.

The 1.0.0 release preserves those features and adds observable CLI versions, actual portable launcher checks and bounded policy/legacy-text format compatibility. Its source and package qualification scope is recorded in [verification](verification.md#stable-100-release); the linked release record identifies the independent-review disposition and limitations.

Later possibilities include more policy presets and team-maintained local rules. A remote evidence service, mandatory account, paid processing, automatic screenshot secret detection and a guarantee of finding every personal value are outside scope.
