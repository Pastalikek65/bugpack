# Roadmap

MVP: working local HAR/log/screenshot review and clean ZIP export with actual Windows/Linux static-package acceptance. Public preview publication follows usable tested MVP; no blank public repository is planned.

Beta/v1: versioned local redaction policies, bounded literal custom rules, supported JSON and URL-encoded form body cleanup, explicit binary/unsupported omissions, batch evidence processing and a CLI sharing the same text redaction engine. Each stage requires independent review and fresh actual package evidence.

Later possibilities include more policy presets and team-maintained local rules. A remote evidence service, mandatory account, paid processing, automatic screenshot secret detection and a guarantee of finding every personal value are outside scope.
